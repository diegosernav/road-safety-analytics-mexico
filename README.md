# Road Safety Analytics — Mexico

An academic data analytics project examining road traffic accidents across Mexico, with a focus on Nuevo León and the Monterrey Metropolitan Area.

Using public INEGI data, the project combines descriptive, temporal, demographic, geographic, geospatial, and predictive analysis to identify patterns and support data-driven road safety decisions.

> **Language:** Project content and visualizations are presented in Spanish.

## Project Outputs

### Interactive Dashboard
The final interactive visualization includes national, state, and metropolitan analyses, as well as geospatial and predictive components.

### Detailed Exploratory Analysis
Supporting descriptive analysis and visualizations covering Mexico, Nuevo León, and the Monterrey Metropolitan Area.
